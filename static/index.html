Each component in this MLOps architecture is modular, reproducible, and monitored in production.

🔄 Continuous Integration (CI)

Triggered on Git commit via GitHub Actions. Runs automated Pytest suite (8 unit & integration tests), checks linting, and validates model serialization.

🚀 Continuous Deployment (CD)

Containerized Docker build packaged for Kubernetes deployment (AWS EKS / Minikube) with horizontal pod scaling and declarative YAML services.

🛡️ Data Drift Monitoring (CM)

Statistical distribution shift evaluation using two-sample Kolmogorov-Smirnov hypothesis testing (p < 0.05) and Wasserstein distance metrics.

📊 Telemetry & Observability

Live Prometheus instrumentation exporting request counts, response latency histograms, drift indicators, and cluster distributions.

📊 20 Sonic Cluster Archetypes

The unsupervised K-Means model partitions the 15-dimensional audio manifold into 20 distinct sonic archetypes. Explore their acoustic footprints and representative tracks.
